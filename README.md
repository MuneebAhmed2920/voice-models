## 🌟 Overview

`marukh-english-model` is a dedicated, self-contained **English Voice Model** engineered specifically for **AI Customer Service Voice Bots**, **Asterisk PBX**, **Vicidial**, and **Real-time WebRTC Voice Agents**.

It packages the calibrated English vocal identity of **Mahrukh (Marukh / ماہ رخ)** — a warm, friendly, articulate, and melodious female customer service representative.

### Key Highlights:
- **Calibrated Speaker Identity**: Directly conditioned on the 24kHz clean studio master reference recording (`user_english_master_24k.wav`).
- **Acoustic Profiling**:
  - Fundamental Pitch (F0 Mean): `281.67 Hz` | Median F0: `280.40 Hz`
  - High-SNR Voice Clone Prompt: `prompt/marukh_english_prompt.pt`
  - Warm, polite, conversational pacing with natural prosody.
- **Dual Studio HD & Telephony Audio Pipeline**:
  - **24,000 Hz HD Studio Master**: Crystal-clear uncompressed linear audio for web apps, mobile apps, and broadcast.
  - **8,000 Hz PSTN Telephony**: Hardware-accurate G.711 telephone line bandpass filtering (300Hz–3400Hz Butterworth 4th-order) for direct PBX / VoIP transmission.
- **Built-in Conversational Text Normalizer**:
  - Currencies (`$49.99` $\to$ `49.99 dollars`)
  - Honorifics & Abbreviations (`Dr.` $\to$ `Doctor`, `Dept.` $\to$ `Department`)
- **FastAPI & OpenAI Drop-In Compatibility**:
  - Custom synthesis (`/v1/tts/synthesize`)
  - OpenAI-compatible speech endpoint (`/v1/audio/speech`)

## 🚀 Quickstart

### 1. Installation

```bash
git clone https://github.com/MuneebAhmed2920/marukh-english-model.git
cd marukh-english-model
pip install -r requirements.txt
pip install -e .
```

### 2. Python API

```python
from marukh_english_model import EnglishVoiceModel

# Initialize singleton model (loads weights and cached prompt once)
model = EnglishVoiceModel()

# Synthesize 24kHz Studio HD Audio
audio_hd, sr = model.synthesize(
    text="Hello, thank you for calling. My name is Mahrukh, how may I assist you today?",
    sample_rate=24000,
    output_file="greeting_hd.wav"
)

# Synthesize 8kHz Telephony Line Audio (for Asterisk / Vicidial)
audio_8k, sr_8k = model.synthesize(
    text="Your payment has been successfully confirmed, and your package will be dispatched shortly.",
    sample_rate=8000,
    telephony_filter=True,
    output_file="confirmation_telephony.wav"
)
```

### 3. Run the Telephony REST & OpenAI API Server

```bash
uvicorn marukh_english_model.server.app:app --host 0.0.0.0 --port 8000
```

#### API Endpoints:
- **`GET /health`**: Health check and model readiness.
- **`POST /v1/tts/synthesize`**: Custom synthesis with sample rate and telephony filtering.
- **`POST /v1/audio/speech`**: OpenAI-compatible speech synthesis for standard AI bot frameworks.
